# Agrovet.Care.Go — Veterinaria Carela Gomez

Sitio web estilo botánico natural con página de inicio tipo menú y dos secciones.

## Archivos de imagen
- `logo.png` — Logo oficial (fondo transparente)
- `img/hero-loro.jpg` — Foto héroe de la sección mascotas
- `img/hero-ganado.jpg` — Foto héroe de la sección productores
- `img/divider.jpg` — Divisor botánico decorativo

## Estructura

- `index.html` — Página de inicio: "¿Eres productor o tienes una mascota?"
- `productor.html` — Servicios para animales de producción (ganadería)
- `mascotas.html` — Veterinaria de exóticos + catálogo de aves
- `aves.json` — Datos del catálogo de aves (nombre, descripción, alimentación, hábitat, precio, estado)
- `logo.png` — Logo oficial (fondo crema)
- `style.css` — Estilos (diseño zen minimalista + botánica natural)

## Cómo publicar

Sube todos los archivos a tu hosting (misma carpeta). Abre `index.html`.

## Para personalizar

- **WhatsApp:** busca `18095551234` en los archivos `.html` y reemplázalo por tu número real (con código de país, sin `+`).
- **Aves:** edita `aves.json` para agregar, quitar o cambiar aves del catálogo.
- **Colores:** ajusta las variables en `:root` al inicio de `style.css`.
